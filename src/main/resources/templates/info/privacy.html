개인정보 안내

객석은 포트폴리오 프로젝트입니다. 실제 예매와 결제가 이뤄지지 않으므로 평소 쓰는 비밀번호나 실제 결제 정보를 입력하지 마세요.

수집하는 정보

  • 회원가입: 아이디, 비밀번호(암호화해 저장), 닉네임, 이메일
  • 카카오·네이버 로그인: 해당 서비스의 회원 식별값과 닉네임
  • 이용 내역: 예매, 찜, 관람평, 저장한 검색, 알림
  • 접속 기록: 서버 로그에 남는 IP 주소 등

이용 목적

  • 로그인과 비밀번호 재설정
  • 예매, 찜, 알림 등 사이트 기능 제공
  • 오류 확인과 사이트 운영

브라우저에 저장하는 정보

로그인 유지에 세션 쿠키를 씁니다. 최근 본 공연과 비교함은 이용자의 브라우저에만 저장합니다.

외부 서비스

  • AWS: 서버와 데이터베이스 운영
  • Cloudflare: 접속 중계와 보안
  • 토스페이먼츠: 테스트 모드 결제. 실제 대금이 청구되지 않습니다.
  • 카카오·네이버: 소셜 로그인, 공유, 지도

보관과 삭제

회원 탈퇴 기능은 아직 없습니다. 삭제를 원하시면 아래 GitHub 저장소로 요청해 주세요. 이슈는 공개되므로 개인정보를 적지 말고 아이디만 알려 주세요. 프로젝트 운영을 마치면 데이터를 함께 삭제합니다.
